# WhosTV 签到（Egern）

## 说明
自动抓取 whos.tv Cookie 并每日签到；这是 `whos` 仓库里的 Egern 版入口，与 `QuantumultX/WhosTV签到` 为同一脚本的两种客户端封装。

## 文件
- `WhosTV签到.module` — Egern 模块入口
- `WhosTVSignin.js` — 签到脚本（已本地化）
