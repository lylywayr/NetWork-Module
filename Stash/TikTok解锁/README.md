# TikTok 解锁

## 说明
按地区解锁 TikTok，同一目录内保留美 / 日 / 韩 / 台四个区域配置，按需启用其中一个。

## 文件
- `TikTok-US.stoverride`
- `TikTok-JP.stoverride`
- `TikTok-KR.stoverride`
- `TikTok-TW.stoverride`

## 安装
- Stash：导入对应地区的 `.stoverride`，不要同时启用多个。

## 来源
- 由原 `TikTok 美区 / 日区 / 韩区 / 台区` 四个目录合并而来，规则内容未改。

## 维护记录
- 2026-11-24：合并为单目录（同功能只保留一个三级目录）。
